# 🧠 LogicaEmJS

Repositório criado para praticar **lógica de programação com JavaScript**, por meio de exercícios e desafios de diferentes níveis de dificuldade.

A ideia é desenvolver o raciocínio lógico, praticar conceitos fundamentais da linguagem e ganhar mais confiança na resolução de problemas com JavaScript.

## 📚 Objetivos

- Praticar lógica de programação
- Desenvolver o raciocínio para resolução de problemas
- Reforçar conceitos fundamentais de JavaScript
- Praticar diferentes formas de resolver um problema
- Evoluir gradualmente através de exercícios

## 🛠️ Tecnologias

- JavaScript
- Node.js
- npm

## 🚀 Como rodar o projeto

### 1. Clone o repositório

```bash
git clone <URL_DO_REPOSITORIO>
```
### 2. Acesse a pasta do projeto
```bash
cd LogicaEmJS
```
### 3. Instale as dependências
```bash
npm i
```
### 4. Execute o projeto
```bash
npm run dev
```
## 📌 Conteúdos praticados
- Variáveis e tipos de dados

- Operadores

- Condicionais (if, else, switch)

- Estruturas de repetição (for, while)

- Arrays

- Objetos

- Funções

- Métodos de arrays

- Manipulação de strings

- Resolução de problemas

## 🎯 Como praticar
A recomendação é tentar resolver cada exercício sem consultar a solução inicialmente.

Depois de finalizar, analise sua solução e tente identificar:

Como o problema foi dividido

Quais conceitos foram utilizados

Se existe uma solução mais simples

O que poderia ser melhorado no código

## 📈 Progresso
Este projeto será atualizado conforme novos exercícios forem adicionados.
